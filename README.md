# Overseas Kids

Premium responsive international-school admissions landing page for Overseas Kids by Overseas Highway.

## Features
- Mobile and desktop responsive layout
- School spotlight, curriculum and admissions journey
- Consultation form preparing a WhatsApp message to +8801332843551
- Floating WhatsApp contact button

## Preview
Open `index.html` locally. Google Fonts and illustrative Unsplash images require an internet connection.

## GitHub Pages deployment
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, set **Source: Deploy from a branch**.
3. Choose **main** and **/(root)** and click **Save**.
4. Once GitHub reports deployment as complete, open the published URL shown in Pages settings.

## Before public launch
- Replace the provisional typographic logo with the official approved brand logo.
- Use licensed/approved school photography; current photography is illustrative and does not claim to show KTJ.
- Verify programme and school-partnership claims.
- Add appropriate privacy/legal information when collecting lead data through any future backend.

This is a static website. Enquiry fields are not stored: submission opens a WhatsApp draft that the visitor chooses to send.
